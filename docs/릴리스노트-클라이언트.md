# 홈페이지 개선 안내 — 요약본

> 이번 업데이트로 홈페이지를 **최신 기술로 새로 구축**했습니다. 보이는 화면과 기능은 그대로지만, **더 빠르고 안정적**으로 동작하며 **운영 비용도 줄었습니다.**

---

## 무엇이 좋아졌나요?

### 1. 페이지가 더 빨라졌어요
- 메인 화면의 무거운 이미지를 대폭 가볍게 만들었습니다. **메인 인트로 이미지 용량이 약 25MB → 1.8MB로 줄어** 첫 화면이 훨씬 빨리 뜹니다.
- 사이트 전체를 미리 만들어 두는 방식으로 바꿔, 접속할 때 기다리는 시간이 줄었습니다.

### 2. 첫 화면 흔들림이 사라졌어요
- 메인 인트로 영상에서 사진으로 넘어갈 때 화면이 살짝 **출렁이던 현상을 없앴습니다.**
- 페이지가 뜰 때 요소들이 **밀려 움직이던 흔들림(레이아웃 깜빡임)도 제거**해 더 깔끔하게 보입니다.

### 3. 이미지가 더 선명하고 정확해졌어요
- 사진이 **찌그러지거나 늘어나 보이던 문제를 해결**했습니다(작품 상세, 구성원, 뉴스 이미지 등).

### 4. 다국어와 검색은 그대로 동작해요
- **한국어 / 영어** 전환이 그대로 정상 동작합니다.
- 뉴스 **검색 기능도 그대로** 사용할 수 있습니다.

---

## 비용·운영 측면

- 그동안 뉴스 검색에 쓰던 **외부 유료 검색 서비스(Algolia)를 제거**했습니다.
  → 검색은 사이트 자체 기능으로 대체되어 **동일하게 동작하면서 매월 나가던 비용과 관리 부담이 줄었습니다.**
- 사이트 운영 구조를 단순화해 **앞으로 유지보수와 수정이 더 쉬워졌습니다.**

> 참고: 비용을 완전히 멈추려면 Algolia 서비스 해지(대시보드에서 인덱스 삭제) 한 번이 필요합니다. (개발팀에서 처리)

---

## 달라지는 점 (확인 필요)

- 페이지 **주소(URL) 형식이 바뀝니다.** 예: `…/work` → `…/ko/work`, `…/en/work` (한국어/영어 구분).
  - 즐겨찾기(북마크)나 외부에 공유된 기존 링크가 있다면 새 주소로 갱신이 필요할 수 있습니다.
  - 검색엔진 노출(SEO)에 일시적 영향이 있을 수 있어, 배포 후 모니터링이 권장됩니다.

---

## 한 줄 정리

> **보이는 건 그대로, 속은 새것** — 더 빠르고, 흔들림 없고, 비용은 줄어든 홈페이지가 되었습니다.
